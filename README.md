# E-Commerce Customer Segmentation using K-Means and DBSCAN

## 📌 Project Overview

This project focuses on **E-Commerce Customer Segmentation** using Machine Learning clustering algorithms. It analyzes customer purchasing behavior using RFM (Recency, Frequency, Monetary) analysis and groups customers into meaningful segments.

The project applies K-Means and DBSCAN clustering techniques, uses PCA for dimensionality reduction, and t-SNE for visualizing customer segments. Based on the identified clusters, actionable marketing personas and strategies are generated to help businesses improve customer engagement and retention.

## 🎯 Objectives

- Analyze customer purchasing behavior using RFM analysis.
- Segment customers using K-Means clustering.
- Apply DBSCAN to identify customer groups and unusual purchasing patterns.
- Reduce data dimensions using PCA.
- Visualize customer segments using t-SNE.
- Generate customer personas and targeted marketing recommendations.
- Compare the performance and outcomes of K-Means and DBSCAN.

## 📂 Dataset

**Dataset:** [E-Commerce Data – Kaggle](https://www.kaggle.com/datasets/carrie1/ecommerce-data)

The dataset contains online retail transaction records.

Important features include:

| Feature | Description |
|---|---|
| InvoiceNo | Unique invoice number |
| StockCode | Product identification code |
| Description | Product description |
| Quantity | Number of products purchased |
| InvoiceDate | Date and time of purchase |
| UnitPrice | Price per product |
| CustomerID | Unique customer identifier |
| Country | Customer's country |

The dataset is downloaded automatically using `kagglehub`.

## ⚙️ Project Workflow

### 1. Data Collection
- Download the E-Commerce dataset using KaggleHub.
- Load the CSV file into a Pandas DataFrame.

### 2. Data Preprocessing
- Handle missing values.
- Convert columns into appropriate data types.
- Remove cancelled transactions.
- Remove duplicate records.
- Remove invalid quantities and prices.
- Calculate total transaction price.

### 3. RFM Analysis

Three important customer metrics are calculated:

- **Recency:** Number of days since the customer's last purchase.
- **Frequency:** Total number of unique invoices generated by the customer.
- **Monetary:** Total amount spent by the customer.

### 4. Data Scaling
- Apply logarithmic transformation using `log1p()`.
- Standardize the RFM features using `StandardScaler`.

### 5. K-Means Clustering
- Determine suitable cluster counts using the Elbow Method.
- Evaluate clustering using Silhouette Scores.
- Apply K-Means with 4 clusters.
- Analyze the characteristics of each customer segment.

### 6. DBSCAN Clustering
- Apply DBSCAN with `eps=0.7` and `min_samples=10`.
- Identify dense customer groups.
- Detect noise points and unusual customer patterns.

### 7. Dimensionality Reduction & Visualization

**PCA (Principal Component Analysis)**
- Reduce the three RFM features into two principal components.
- Visualize K-Means and DBSCAN clusters.

**t-SNE (t-Distributed Stochastic Neighbor Embedding)**
- Reduce customer data into two dimensions.
- Visualize customer segments using a sample of up to 1,500 customers.
